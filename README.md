Ruleset mod for unciv featuring many new policy trees, a new tech tree structure and new interplay between techs and policies.

The goal of this mod is to be a reimagining of the unciv G&K ruleset making tech paths and policy choices more dynamic.

This mod is inspired by the likes of Rekmod, The Great Unciv Rework and Emperors&Deities.

On a scale from realistic to goofy, we're definitely on the more goofy side, the whole conceit of the mod is that it might make for more interesting gameplay if not everyone researches the same techs.
